# Arduino Projects

This repository contains mini Arduino projects to learn real-world embedded programming, electronics fundamentals, and data handling for Electrical Engineering students.

## Projects Included
1. Button → LED control
2. LED blink variations
3. Sensor reading with analog input
4. Sensor array data capture
5. (More coming soon…)

## How to Use
Each folder contains:
- `.ino` Arduino sketch
- brief explanation
- wiring diagram or pin info
